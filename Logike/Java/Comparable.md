La interfaz `Comparable` en Java permite definir un orden natural para los objetos de una clase, haciendo que sus instancias sean comparables entre sí. Al implementar esta interfaz, una clase debe implementar el método [compareTo()](https://www.google.com/search?q=compareTo%28%29&oq=Comparable&gs_lcrp=EgZjaHJvbWUqBwgBEAAYgAQyCQgAEEUYORiABDIHCAEQABiABDIHCAIQABiABDIHCAMQABiABDIHCAQQABiABDIHCAUQABiABDINCAYQLhjHARjRAxiABDIHCAcQABiABDIHCAgQABiABDIHCAkQABiABNIBCDI1NzhqMGoxqAIAsAIA&client=ubuntu-chr&sourceid=chrome&ie=UTF-8&mstk=AUtExfBt4Yshp3xLufwxU36lJzJ2UfSSZfzMiV-zhSnUiOitpFw3JxwCw_gXGepTNgwviTTf--U0YEpSeN3t30iI8apkGXUNFPhDc4TTk_ZnFnNPRer2PKQfCb-oUV3-mzjC4vEgaFqZbcIx5F-TOXeMF-MNX0aah6MdY6NzlFDNMW0XuGGrxSizitospndE9GmNTeUu&csui=3&ved=2ahUKEwjsiLzbiemQAxUBp7AFHbXWDSEQgK4QegQIARAB), que devuelve un entero negativo, cero o positivo para indicar si el objeto actual es menor, igual o mayor que otro objeto del mismo tipo. Esto es fundamental para ordenar colecciones como listas y arrays de forma predeterminada.
