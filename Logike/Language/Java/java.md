#Validators


-   _@NotNull:_ a constrained _CharSequence_, _Collection_, _Map,_ or _Array_ is valid as long as it's not null, but it can be empty. (Integers)
-   _@NotEmpty:_ a constrained _CharSequence_, _Collection_, _Map,_ or _Array_ is valid as long as it's not null, and its size/length is greater than zero.
-   _@NotBlank:_ a constrained _String_ is valid as long as it's not null, and the trimmed length is greater than zero.
