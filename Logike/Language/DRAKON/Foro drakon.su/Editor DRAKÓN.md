## ¿Qué es DRAKON Editor?

DRAKON Editor es un editor para dibujar algoritmos en el lenguaje DRAGON.

DRAKON Editor tiene dos propósitos:

1. Crear diagramas para ilustración y documentación.
    
2. Programa utilizando circuitos DRAGON.
    

Una característica distintiva de DRAKON Editor es su simplicidad. Los diagramas que contiene están compilados, como en un programa de gráficos de oficina, a partir de segmentos y cuadrados.

Si mantiene presionada la tecla Shift mientras edita, se activa un modo "inteligente" único. En este modo, puedes cambiar la forma del diagrama, pero no su contenido. Esto ayuda a aportar rápidamente belleza y orden al diagrama.

Los programadores pueden utilizar DRAKON Editor para generar código fuente a partir de circuitos DRAKON. Se admiten varios lenguajes de programación:

- C y C++ (incluidas extensiones de lenguaje del marco Qt);
    
- Java (así como su subconjunto para gráficos por computadora: Processing.org);
    
- C#;
    
- Python (versiones 2.x y 3.x);
    
- tcl;
    
- JavaScript;
    
- Erlang;
    
- Lúa.
    

Sitio web del editor: [http://drakon-editor.sourceforge.net/](http://drakon-editor.sourceforge.net/ "http://drakon-editor.sourceforge.net/")

## Características adicionales

Además de editar diagramas, están disponibles las siguientes opciones:

- almacenar varios diagramas y un árbol de proyectos en un archivo;
    
- potentes herramientas de búsqueda y navegación;
    
- comprobar la sintaxis gráfica del lenguaje DRAKON;
    
- exportar a PDF;
    
- exportar a PNG.
    

DRAKON Editor admite todos los iconos del alfabeto gráfico del lenguaje DRAGON.

Además de los diagramas DRAKON, utilizando este editor puedes crear otros tipos de diagramas:

- diagramas de secuencia;
    
- diagramas de clases;
    
- diagramas entidad-relación.
    

DRAKON Editor se distribuye en ruso e inglés.

## Requisitos del sistema

Sistemas operativos compatibles: Windows, Mac, Linux.

## Cómo instalar DRAKON Editor

Para utilizar DRAKON Editor primero debes instalar la última versión de Tcl/Tk.

Los usuarios de Mac y Windows pueden descargar Tcl/Tk desde aquí: [http://www.activestate.com/activetcl/downloads](http://www.activestate.com/activetcl/downloads "http://www.activestate.com/activetcl/downloads")

Los usuarios de Linux instalan los siguientes paquetes:

- tcl8.5
    
- tk8.5
    
- tcllib
    
- libsqlite3-tcl
    
- libtk-img
    

En Ubuntu:

sudo apt-get install tcl8.5 tk8.5 tcllib libsqlite3-tcl libtk-img

## Cómo iniciar DRAKON Editor

En Windows:

- descomprimir el archivo zip
    
- haga doble clic en el archivo drakon_editor.tcl
    

En Mac:

- descomprimir el archivo zip
    
- ejecuta DRAKONEditor.app
    

Bajo Linux:

- descomprimir el archivo zip
    
- en la terminal vaya a la carpeta con los archivos descomprimidos y ejecute el comando
    

./drakon_editor.tcl

La versión de Linux se puede iniciar de la misma forma en una Mac en la terminal.
