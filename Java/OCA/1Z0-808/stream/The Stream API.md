The Stream API is your best tool to process your in-memory data following a map/filter/reduce approach.

The tutorials in this series are listed below. They will guide you all through the Stream API, starting at the basic concepts all the way to collector design and parallel streams.

  

1. [Processing Data in Memory Using the Stream API](https://dev.java/learn/api/streams/map-filter-reduce/)  
    
    Implementing the map-filter-reduce algorithm
    
2. [Adding Intermediate Operations on a Stream](https://dev.java/learn/api/streams/intermediate-operation/)  
    
    Deep-diving into the intermediate operations of the Stream API.
    
3. [Creating Streams](https://dev.java/learn/api/streams/creating/)  
    
    Patterns to create the stream you need.
    
4. [Reducing a Stream](https://dev.java/learn/api/streams/reducing/)  
    
    Reducing streams with a binary operator.
    
5. [Adding a Terminal Operation on a Stream](https://dev.java/learn/api/streams/terminal-operations/)  
    
    Reducing a stream without the reduce method.
    
6. [Finding the Characteristics of a Stream](https://dev.java/learn/api/streams/characteristics/)  
    
    Understanding the characteristics of a stream
    
7. [Using a Collector as a Terminal Operation](https://dev.java/learn/api/streams/using-collectors/)  
    
    Collecting a stream in a mutable container using a collector.
    
8. [Creating Your Own Collector](https://dev.java/learn/api/streams/custom-collectors/)  
    
    Creating a collector by using the Collectors factory class.
    
9. [Implementing the Collector Interface](https://dev.java/learn/api/streams/collector-interface/)  
    
    Creating a collector by implementing the Collector interface.
    
10. [Using Optionals](https://dev.java/learn/api/streams/optionals/)  
    
    Introducing the Optional class to model method that cannot produce a value.
    
11. [Parallelizing Streams](https://dev.java/learn/api/streams/parallel-streams/)  
    
    Going faster by leveraging the parallel streams.
    
12. [The Gatherer API](https://dev.java/learn/api/streams/gatherers/)  
    
    Implementing your own intermediate operations with the Gatherer API
